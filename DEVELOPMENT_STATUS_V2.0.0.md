# V2.0.0 modular optional AI runtime

**Implemented:** independent Windows installer for denoise, split, meter, pitch and dereverb with explicit model download. Retains optional all-in-one install for backwards compatibility. Core EXE remains lightweight; no model auto-download. Separate pinned requirements and staged installer. No user audio leaves the machine. Source regressions validate module selection, list-only and selective downloader.

**Not a claim of Windows AI inference acceptance:** PyTorch/DeepFilterNet/Demucs/Beat This! must be separately installed on a real Windows workstation and run against recordings. Professional listening quality and physical device output unverified.
